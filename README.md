# Shot Reviewer · 镜头审核

把详细导演稿变成可审阅的镜头表、左图右文审核卡，以及通过审核后的视频生成单元和参考图计划。

## 安装
`npx skills add Lonc2100/shot-reviewer --skill shot-reviewer`

也可以将本目录复制到支持 Agent Skills 的客户端技能目录。普通 ChatGPT 上传文件只能作为参考材料，不等于安装 Skill。

## 使用
“使用 $shot-reviewer 审核这份导演稿的第二场，先给四列镜头表。”

输入：当前采用的导演稿、审核范围；可补充剧本、批准资产和目标模型能力。
输出：版本化 shot-review.md、按需静态 HTML 图文卡、审核通过后的 generation-plan.md。

用户或项目指定列式优先；否则四列为镜号、景别/角度、画面内容、台词。
不代替编剧或导演创作，不生成最终提示词，不运行生图、生视频或上传平台。

## 前提与排错
需要能读取 Markdown 的 AI 客户端。源稿哈希需要本地文件工具或 SHA-256 工具；未安装其他被提及的 Skill 时保留职责边界，由当前客户端处理或报告缺项，不能假装调用成功。
源稿不唯一时先选母版；源稿修改后旧计划失效。图片不准确就留空，未经批准的图不能进入正式绑定清单。
