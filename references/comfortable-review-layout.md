# 舒服版逐镜图文审核 v001

这是用户认可并要求固定的个人审核版式。触发“图文审核稿”“一图一栏文字”“按舒服版做”“像上次舒服的那版”时，默认使用本版。它只固定呈现方式，不改剧情、镜数、台词或资产批准状态。

## 固定参数

- 页面米灰底 `#f4f3ee`，正文深灰绿 `#263c39`，系统中文字体，无外链字体。
- 主体最大宽度 1080px，外边距居中，内边距 32px 28px 70px。
- 一镜一行 CSS Grid：180px 图片栏 + 自适应文字栏，间距 26px；每镜上下留白 28px，以细线分隔。
- 缩略图宽 160px，按原图比例展示，单图优先不超过 15KB；点击查看原图。图不匹配时显示 160×90 的浅虚线空位与“—”。
- 正文 17px、行高 1.8；镜号标题 21px，页面标题 30px。摄影与声音 13px、图注 12px，以灰绿色弱化。
- 文字次序：场景时间／可选参考秒数→镜号标题→必要摄影说明→画面动作→台词→必要声音。不臆造未提供的焦段、设备或秒数。
- 每位说话人的台词独立成段，说话人加粗，左侧 3px 浅棕竖线。不得为排版缩写、切碎或重写台词。
- 顶部只放标题、版本状态、一行事件脉络及少量全局约束；不加工具栏、按钮墙、巨幅封面或流程状态仪表盘。
- 650px 以下沿用模板的窄屏参数。长内容让页面自然向下延伸，不为了塞进一屏缩小正文。

## 图文对应

先确定导演内容，再检查旧图的身份、人数、坐站状态、画面方位、道具、动作与日夜。只有对应才附。静态图只覆盖长镜中一个时刻时，用小图注说明，不能声称整镜已有图。不通过翻转、重绘或擅自补图伪造匹配。

## 复用方法

直接复制 `../templates/visual-review-card-comfortable.html` 的 CSS 和行结构，转义所有插入文本；一条镜头数据重复一次 article。同一行只能有一个图片位置和一个文字区。未提供的信息整段省略，交付不能留下模板占位符。无对应图时使用模板注释内的空位结构。图片、说明、哈希不能自动变成生成绑定或审核通过。

输出后核对镜号覆盖、台词一致、全部本地链接存在、图片实际加载；做一次桌面截图，检查左图右文和横向溢出。保持新版本输出，不覆盖已批准稿。

用户已在 2026-09-05 明确认可既有项目的合并版逐镜审核页的阅读体验并要求固定，这是个人呈现偏好，不是某模型优于另一模型的对照证据。原样提取已认可 CSS 为可验证复用点；跨模型体验一致性仍需实际使用验证。
