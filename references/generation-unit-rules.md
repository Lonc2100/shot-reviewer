# 视频生成单元切分规则

## 1. 定义

一个视频生成单元是一条准备交给一次视频生成请求的连续内容。它可以包含多个传统镜头和多个表演节拍；传统镜头数、问答次数和情节节拍数都不是单独的切分依据。

切分目标不是把导演稿平均分段，而是让每个单元具有：

- 一个主要叙事任务；
- 一条可连续执行的主要动作链；
- 一个可理解的核心空间和时间；
- 可控的角色、道具和特效负担；
- 明确的开始状态和结束状态。

## 2. 决策顺序：先输入包，再容量，再动作

切分必须按以下顺序判断：

1. **参考图包**：本段需要哪些环境／机位母图、角色身份图、道具／VFX 图和关系锚点；
2. **生成容量**：目标模型或项目已声明的最长时长、参考图数量、首尾帧和声音模式；
3. **连续性**：地点、时间、现实层、光向、轴线、人物和道具状态是否可持续；
4. **动作负载**：连续对白、动作、反应和镜头变化是否在当前容量内可执行；
5. **最终切点**：只在前四项不能同时成立时拆分。

参考图包可用一个轻量指纹表示：

```text
环境／机位母图 + 主要角色集合 + 关键道具／VFX + 关系锚点模式 + 生成模式
```

相邻镜头指纹相同且时长可容纳时，默认合并。指纹变化是候选切点，不是自动切点；例如背景人物暂时进出但不需要新增身份参考时，可以继续同段生成。

## 3. 优先保持在同一单元的情况

- 同一地点、时间和现实层；
- 同一连续表演或对话压力；
- 同一主要动作目标；
- 同一核心空间拓扑和人物关系；
- 镜头变化能通过动作、视线、跟焦、推拉摇移或自然反打完成；
- 人为拆开会制造新的表演重置或动作接缝。
- 参考图包相同，预计总时长未超过当前已知上限。

例如，人物走向桌边、停步、拿起文件并翻到指定页面，是一条连续动作，不应逐镜拆成多个生成请求。

## 4. 应拆分的情况

出现下列任一强变化时优先拆分：

1. 地点或时间改变；
2. 现实、回忆、梦境或其他叙事层改变；
3. 第一视角与客观视角互换；
4. 核心空间方向、正反机位母图或空间权威改变，导致参考图包无法共用；
5. 主要角色、关键道具／VFX 或关系锚点发生实质变化；
6. 一段包含多次完整攻防反转或结果重置，导致对白／动作负载过高；
7. 角色、场景、道具和 VFX 同时过载，模型难以维持职责；
8. 预计时长、输入数量或生成模式超过当前已知能力。

新的问答、表情反应、台词落点或小动作目标变化，本身不足以拆分。先问：它是否仍能共用同一参考图包，并装入同一次生成容量？

不同环境不要放在同一连续变形指令中让模型自行猜切换点。地点 A 到地点 B、室外到室内、现实到回忆等，优先用遮挡、黑场、声音或后期硬切后分成不同单元。

## 5. 打斗与复杂动作

按因果节点而非平均秒数切：

```text
动作启动 → 受力/撞击 → 结果反应 → 新关系
```

一个单元可以覆盖其中一整条连续链，但不宜同时塞入多次“压制—翻盘—再压制—再反杀”。下一个单元从已经成立的新关系开始，不要求模型完整复刻上一单元所有站位。

镜头切到脸部或道具特写时，画面边缘保留仍在持续的抓握、受力、前景手臂或运动方向，避免动作冻结后重置。

## 6. 跨单元接缝

每个边界选择一个主要接缝载体：

- 动作
- 视线
- 声音
- 物件
- 反应
- 遮挡
- 黑场
- 结果

不要让一个接缝同时依赖多个难以复刻的变量。上一段末帧只能提供状态参考，不能独自保证色调、速度、角度和空间连续。

## 7. 非线性素材单元

同一机位、角色状态和美术空间反复出现的插镜，可以独立为素材采集单元，一次生成后剪出多处使用。它不改变主流程单元的动作边界。

## 8. 镜头覆盖

切分后做一次最小覆盖核对：

- 审核范围内每个镜号必须进入一个主单元；
- 复用插镜、补拍或主动省略必须明确标注；
- 同一镜号无意出现在多个主单元，或任何镜号无人承接，都视为未通过。

## 9. 模型与时长

- 不使用统一的 4～15 秒硬规则。
- 已指定目标模型：只从当前官方文档、平台 schema 或节点回读确认时长、首尾帧、多参考和音频能力。
- 用户或项目已声明可用上限：允许填写规划时长，并注明依据为 `用户／项目声明`；这是一项生产假设，不是官方能力声明。
- 目标模型和项目上限都未知：省略时长，写 `待模型校准`。
- 对话长度、动作数量、反应气口和镜头变化会影响容量，但不能只靠镜头数量计算。
- 规划时长必须覆盖台词自然语速、动作执行和必要反应气口；不能只用字数机械换算。
- 规划时长属于生成计划和平台参数。平台已有时长参数时，最终提示词正文不必重复总时长。
- 如果模型产生非预期切镜，先判断动作序列是否过载、时长是否不足或文字是否暗示剪切，再决定延长或拆分。

## 10. 生成计划审核

顶部简表只显示：

```text
单元｜镜号范围｜规划时长｜主要内容｜合并／拆分理由｜参考图包
```

后台详情必须记录起始状态、结束状态、主要接缝、连续性风险和模型状态，但用户没有要求时不要把这些字段复制进镜头审核表。
