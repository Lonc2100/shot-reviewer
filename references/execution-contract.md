# 执行合同与分层验收

- 用户当前明确要求优先于项目旧约定，项目明确列式优先于本 Skill 默认；默认四列不构成跨项目硬限制。六列模板可用，但不把六列强加给其他项目。
- 源文件哈希只证明内容一致；还要核对当前采用关系、审核范围与状态。局部提案不是全场母稿，已确认剧情不是所有旧机位都已批准。
- 纯排版只承诺内容保真；导演审核另查取景边界、观看对象、动作阶段、声画接点和修改后的邻镜。结构检查不能替代语义判断。
- 若取景写腰部／膝部／全身，却标为单人近景或特写，须复核边界；局部特写和镜内变景别按实际范围判断，不用词频机械判错。
- 每镜先问删除后损失什么，再问替代方案为何不选。“情绪递进／关系变化”须落到具体表演或空间结果，不默认接受解释。
- 长留与切镜都由新增信息、动作及表演决定，不以固定秒数、台词句数或近景比例判定；必要的宽镜可以保留。
- 对时间、地点、现实层变化，记录真实尾镜与首镜、故意省略和声音／画面接点。修局部后检查受影响片段及前后连接，未授权的剧情改动留作提案。
- 单独报告机械检查、作者语义复核、用户审核及样片验证。作者自审不称独立盲审，未生成不声称成片节奏已验证；有未解决问题时交付明确待审项。
