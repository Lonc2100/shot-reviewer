# 导演镜头审核规则

本文件只负责判断镜头是否清楚、可拍、可剪、可连续生成。用户看到的列式优先遵从当前用户／项目约定，未指定才用四列审核表，不要把内部检查项全部塞进表格。

## 1. 字段写法（列式按当前合同）

### 镜号

- 保留导演母版原镜号；新增镜头使用与项目一致的后缀规则，例如 `6-02A`。
- 不因重新排序而静默改号。需要改号时说明映射关系。

### 景别／角度

先写主体或对象，再写景别；只补真正有意义的角度、机位关系或运镜。

推荐：

- `角色甲脸部近景`
- `桌面文件特写，高机位俯拍`
- `双人中近景，门外反看`
- `角色甲主观近景，轻手持`
- `关键人物大近景，低机位仰拍，缓慢推进`

省略：平视、普通正面、普通固定机位。不要为了“电影感”强行把所有镜头写成特殊角度。

注意：

- 高／低机位描述摄影机高度；俯／仰拍描述镜头朝向，两者不能混为一谈。
- `顶拍` 是接近垂直向下的极端俯视，只有空间图形、压迫或结果确认确实需要时使用。
- `过肩`、`门内反看`、`背侧` 等关系词应帮助判断轴线、视线或空间，而不是装饰词。

### 画面内容

只写摄影机能看到的核心信息：

```text
主体 + 关键动作 + 必要结果
```

写：`角色甲伸手拿起文件；翻到签字页后停住。`

不写：`角色甲终于明白对方的真实意图，内心十分震动。`

微表情也必须可见，例如眼神、呼吸、下颌、肩膀、手指和停顿。不要提前补全材质、镜头参数、光效细节和负面提示词。

### 台词

- 保留原台词、说话人和画内／画外关系。
- 无台词使用 `—`。
- 不在镜头审核阶段为模型自动加对白，也不要求预录正式对白。

## 2. 相邻镜头内部检查

### 景别变化

- 避免机械地按 `远景 → 中景 → 近景 → 特写` 逐级切换。
- 同一主体、同一轴线硬切时，原则上跨两个景别层级。
- 机位绕主体变化约 30° 以上时，可只跨一个景别层级。
- 中景必须承担人物关系、动作或空间交代；不能只因它“最安全”而反复使用。

### 轴线和方向

检查：

- 人物左右关系是否稳定；
- 视线方向能否互相接上；
- 人物进出画方向是否连续；
- 道具握持手、位置和状态是否一致；
- 正反打是否来自同一可理解空间。

如需越轴，必须有运动镜头、中性正面、明确空间建立或其他可理解的越轴理由。

人物实际处于同一侧时，不要为了“电影感”强行写过肩或前景肩膀；这会暗示错误的对置关系。换到新的机位半空间或反打方向后，必须重新判断画面左右、前后深度和视线，不能照抄上一机位。

### 动作匹配

上一镜未完成的动作，下一镜应继续动作、承接受力或明确交代结果。特写不能让伸手、起身、接触或奔跑状态消失，然后回到中景重新摆姿势。

复杂动作优先保持：

```text
动作启动 → 受力/局部动作 → 结果反应 → 新关系
```

### 气口和反应

- 关键动作后保留足够读懂结果的反应或停顿。
- 不把每个人的反应都切成独立卡片；优先让一次横移、拉远、双人镜头或群体镜头同时交代。
- 台词不能让正在发生的主要身体动作突然停止。

### 过渡镜头

过渡必须承担任务，可使用：

- 动作桥
- 视线桥
- 声音桥
- 物件桥
- 遮挡切
- 空镜
- 黑场
- 结果镜头

不要为了“顺滑”添加没有叙事作用的空镜。

## 3. 如何向用户暴露问题

### 源稿语义复核

SHA-256 一致只证明读取的是同一份文件，不等于内容语义通过。审核时还要最小核对：

- 行动或台词明确指向谁；
- 说话人与画内／画外关系是否一致；
- 当前事件类型是否与后文回收、running gag 和链式因果一致；
- 角色标签、动作和台词是否互相支持。

若后文把一组事件明确回收为“表白”，前文却只表现为普通加联系方式；或画面拦住甲、台词却明显向乙说话，应作为语义冲突提出，不能因为逐字复制母版就判为通过。

默认把成立的判断直接落实进当前列式的表格，不展示长篇自检。只有以下情况才在表格外提出：

- 会改变剧情事件或台词；
- 存在两种明显不同的导演选择；
- 空间、动作或视线无法由现有信息判断；
- 修复需要新增镜头或删除现有镜头；
- 用户需要决定节奏取舍。

AI 主动建议改母版时使用最小格式：

```markdown
建议修改 <镜号>
- 原内容：...
- 建议内容：...
- 原因：会造成的具体空间、动作或剪辑问题
```

用户确认前不得写回母版。

## 4. 可选的构图探索

只有关键转折、关系压力或空间权力镜头尚未定稿时，才把少量镜头交给 `cinema-dna-21x9x3` 的剧集镜头顾问模式。只取四项：观众位置、关系压力、视线流量、一个主要构图决定；按本项目画幅和美术体系转译。用户批准后再回写导演母版，普通覆盖镜头不逐镜调用。
